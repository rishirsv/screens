# Comparing directions

Vary one primary decision clearly enough that the options can be judged, with secondary choices supporting it. For example, compare a task-first compact layout with a narrative layout and a visual overview, while keeping the same core content and viewport. Each must meet the same usability and readability floor; a broken option is not a useful contrast.

Work at the fidelity the question requires. Early exploration needs the defining composition and realistic content, not every secondary state. A choice about interaction needs enough working behavior to experience it. Do not polish one direction far beyond the others before the comparison.

Preserve the names and existing options when revising. If asked to combine options, identify the structure, styling and behavior taken from each, then show the result as a coherent direction. Once the person selects an option, continue from that object rather than rebuilding it.
